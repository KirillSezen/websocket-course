# Node.js websocket-course (client)

## Описание
Курс по изучению WebSocket на примере paint-like приложения (Клиент).

Реализовал: Компоненты - Canvas, SettingBar, ToolBar;
Инструменты - Brush, Circle, Eraser, Line, Rect, Tool;
Хранилища - CanvasState, ToolState;

## Стек
React, Vite, axios, bootstrap, mobx, sass.
